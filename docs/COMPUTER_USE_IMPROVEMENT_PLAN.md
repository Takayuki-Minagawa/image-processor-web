# コンピューターユース改善計画

作成日: 2026-10-14（日本時間）

## 目的と対象

ユーザー提供の `調査結果.md` にある CU-01〜CU-10を、現在の Pixelweave Studio に反映する。資料内の改善案は要件の根拠として検討し、現行実装と照合して実装方法を決定する。開始時の main は監査対象と同じ `ebe9d16007d0839fd3c664dc816a316bcdfaed1f`、作業ツリーは clean。

CU-10は資料ではソースからの未確認候補である。今回の調査でも進捗・キャンセルが busy 時の inert の子孫にあることを確認した。ブラウザ回帰検証を実施し、実装確認と実機再現を区別して結果を記録する。

## GitHub・仕様調査

- [既存 Issue #5](https://github.com/Takayuki-Minagawa/image-processor-web/issues/5): 状態管理の分割、国際化、未接続機能の整理が継続課題。今回追加する部品は小さく分離し、新規文言を翻訳辞書に置く。Issue全体の完了は今回の範囲に含めない。
- [既存 PR #6](https://github.com/Takayuki-Minagawa/image-processor-web/pull/6): 入力欄・IME・モーダル中のショートカット抑止、書き出し、既存E2Eの前提を確認。既存の入力保護と保存形式を利用する。
- [React input](https://react.dev/reference/react-dom/components/input): controlled input は入力時に文字列stateを同期する。数値モデルと編集中文字列を分離し、空欄・負号・小数点を含む途中状態を保持する。
- [MDN inert](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inert): 子孫もクリック・フォーカス・アクセシビリティツリーから除外される。進捗とキャンセルを無効化領域の外に表示する。
- [MDN aria-current](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Attributes/aria-current): ページや手順の現在位置を意味的に表現する。ページ選択と履歴の現在位置に適用する。

## 検証方針

- 数値入力: 空文字を即座にモデルへ反映しない。Enter/blurで検証・確定、Escapeで取消。範囲外・非数値を説明する。
- 履歴: 単体で分岐・上限・重複・resetを確認し、ブラウザでマークとレイヤー数がUndo/Redoに追従することを確認する。
- テキスト: 本文・フォントサイズ・ロック保護・複数選択、Undo/Redoを確認する。
- ブラウザ: 390×844、1180px前後、1440×1000でのヒット領域と到達性、名前付きrange、調整数値、ページ状態、テキスト編集、処理キャンセルを検証する。
- `npm run check`（format / lint / unit / typecheck / production build / bundle budget）と関連Playwright E2Eを実行する。既存テストに影響がある場合は関連する全体E2Eまで広げる。
- 既知のmacOS/Linuxフォント差による既存画像比較や、4K性能テストの揺らぎは、今回の差分による失敗と分けて扱い、閾値やbaselineを根拠なく変更しない。

### PR作成前レビューの修正

- 画像デコード終盤のキャンセルで、rollbackが選択・ズーム・パンを初期化し、選択変更通知によって調整値も失われる問題を再現した。AbortSignalをデコーダーに渡し、キャンバス変更前に中断する方式へ変更。Fabricが中断時に返すEventもAbortErrorへ正規化した。回帰テストで選択オブジェクト・viewport・履歴の保持、不要な選択通知の抑止、未使用画像の破棄を確認した。
- X=0から0.04を確定後に左揃えすると、実座標0に対して入力欄だけ0.04が残る問題を再現した。変形欄へ実値を渡し、表示とアクセシビリティ値を同期する。左端・上端への整列で発生する機械精度程度のゼロ残差のみ補正し、他軸の小さな座標は保持する。エンジンとブラウザの回帰テストを追加した。
- 修正箇所を別担当が再レビューし、追加指摘なし。修正後のformat / lint / 全単体テスト / 型チェック・本番ビルド・bundle budget / 新規E2Eを確認した。
