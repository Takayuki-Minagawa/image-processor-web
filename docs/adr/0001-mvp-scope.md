# ADR-001: MVPの製品範囲

- 状態: Accepted
- 日付: 2026-07-30

## 決定

デスクトップブラウザ向け、local-first、sRGB相当8bit RGBAのレイヤー画像編集をMVPとする。PNG/JPEG/WebP、基本図形・テキスト・ブラシ・消しゴム、レイヤー属性、基本フィルター、履歴、独自保存、オフライン起動を含める。

PSD/XCF互換、RAW、CMYK、16/32bit、共同編集、生成AI、高度な選択マスクは対象外とする。

## 理由

ファイル互換や色管理を先に含めると、主要ワークフローを検証する前に製品規模が膨らむ。画像を端末外へ送らない編集フローを先に完成させ、性能と利用状況の測定結果から拡張する。
